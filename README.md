# Travel Bucket List

A responsive React + Vite travel discovery site. Browse curated destinations, search and filter by category, save places to a persistent bucket list, mark visits, and create trip plans with dates and budget breakdowns.

## Get started

```sh
npm install
npm run dev
```

## Commands

- `npm run dev` — start the development server
- `npm run build` — create a production build
- `npm run preview` — preview the production build
- `npm run lint` — run ESLint

Bucket-list items, visited places, account profile, planner draft, and saved trip plans are stored in the browser's local storage. Account and contact forms are local UI demonstrations and do not use a backend. Destination photography is served by Unsplash.
